# FastAPI - 进阶学习

## 中间件

使用中间件为每个请求前后添加统一的处理逻辑。中间件是一个在每次请求进入 FastAPI 应用时都会被执行的函数。它在请求到达实际路径操作（路由处理函数）之前运行，并且在响应返回给客户端之前再运行一次。

### 适用场景

- 多个接口都需要验证用户身份
- 多个接口都需要记录日志、性能数据

### 可完成的操作

- 日志记录
- 身份认证
- 跨域处理
- 响应头处理
- 性能监控

### 使用方式

函数顶部使用装饰器：

```python
@app.middleware("http")
```

## 依赖注入

使用依赖注入系统来共享通用逻辑，减少代码重复。

### 使用步骤

1. 创建依赖项
2. 导入 Depends
3. 声明依赖项

### 中间件和依赖注入的区别

- **中间件**：控制所有请求
- **依赖注入**：由开发者指定

相关概念：

- **依赖项**：可重用的组件（函数/类），负责提供某种功能或者数据
- **注入**：FastAPI 自动帮你调用依赖项，并将结果"注入"到路径操作中

### 优点

- **代码复用**：一次编写，多处使用
- **解耦**：业务逻辑与基础设施代码分离
- **易于测试**：轻松地用模拟依赖替换真实依赖进行测试

### 应用场景

- **处理请求参数**：从请求中提取和验证参数（路径参数、查询参数、请求体）
- **共享业务逻辑**：抽取封装多个路由公用的逻辑代码
- **共享数据库连接**：管理数据库会话的创建、使用、关闭
- **安全和认证**：验证用户身份、检查权限和角色要求等

## ORM(SQLAlchemy ORM)
ORM是一种编程技术，用于在面向对象编程语言和关系型数据库之间建立映射。
它允许开发者通过操作对象的方式与数据库进行交汇，而无需直接编写复杂的SQL语句

使用教程:
+ 安装sqlalchemy和aiomysql(异步数据库驱动)
+ 建库、建表run_sync
+ 操作数据：增删查改

优势: 
+ 减少重复的SQL代码
+ 代码更简洁易读
+ 自动处理数据库连接和事务
+ 自动防止SQL注入攻击
